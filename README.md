# 23101694_PM2.5-Investigation
Project title: Long-Term Trends in Air Quality over Northeast Peninsular Malaysia: Insights from CAMS Reanalysis
Project objectives
1) Conduct data preprocessing for Bachok ground station and CAMS EAC4 Reanalysis data
2) Evaluate the accuracy and performance of CAMS EAC4 data
3) To analyse the agreement and discrepancies between CAMS estimates and observed PM2.5 concentrations
4) To determine the suitability of MERRA-2 as a supplementary data source for Bachok station
